# Portfolio

GitHub Pagesで公開しているポートフォリオ用リポジトリです。

このリポジトリは作品そのものを保管する場所ではなく、各公開作品への入口として使用しています。

## 公開ページ

```text
https://dalirurero.github.io/portfolio.github.io/
```

## 掲載作品

### オペレーションチャート VBA

納品データ・納品予定データの取込から、マスタ照合、作業割当、個人別指示書・作業編成表の作成までを行うExcel VBAサンプルです。

作品のVBAコード、サンプルブック、仕様書などは別リポジトリで公開しています。

```text
https://github.com/dalirurero/operation-chart-vba-sample
```

## リポジトリ構成

```text
.
├─ index.md       # GitHub Pagesのトップページ
└─ README.md      # このリポジトリの説明
```

作品が増えた場合は、`index.md`の「Projects」へ順次追加します。

## 公開方針

公開しているサンプルは、実務での開発経験をもとに公開用として再構成したものです。

以下の情報は公開対象から除外しています。

- 会社名・店舗名
- 従業員名
- 実際の商品・取引情報
- 実績値
- 社内システム固有情報
- 社内フォルダ・ネットワーク情報

サンプルデータは架空の内容を使用しています。
